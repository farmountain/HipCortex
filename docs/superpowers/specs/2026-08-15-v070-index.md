## Mathematical Foundations

```
TxEntry_i    = { tx_id: u64 (atomic monotonic), ts: u64, kind: TxKind, record_ids: Vec<Uuid> }
ΔS(i,j)      = fold(TxEntry_i..j) → { ΔM, ΔW, causal_attributions }
P_tx         = episodic_count / capacity_limit   (compaction pressure)
Trigger      = P_tx > 0.80
H(B)         = −Σ p_i log₂(p_i)                 (epistemic entropy, p_i = belief.confidence)
α_ewma       = 0.1
calibration  = 1 − prediction_error_ewma
provenance   = sha256(tx_origin_bytes || belief_id_bytes)
```
